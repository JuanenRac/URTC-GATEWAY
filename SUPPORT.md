# Support Information 🛠️ (URTC-GATEWAY)

Thank you for using URTC-GATEWAY! Here is how you can get help:

## 📺 Video Tutorials & Demos
The official YouTube channel covers the ecosystem's tools:
[youtube.com/@electrohobby3d](https://youtube.com/@electrohobby3d)

## ✉️ Direct Technical Inquiries
For questions about the options, the identifier list or how to put the gateway in front of a bus:
Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports
If you found a frame the gateway forwards that the specification refuses, an option that does not do what `docs/POLICY.md` says, or a defect in the command line, please open a **GitHub Issue** in this repository and say which option and which identifier.
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?
- Questions about running a specific tool belong in that tool's own repository.
- Please do not use Issues for "How to" questions.
